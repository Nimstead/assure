# Nimstead documentation design

The wiki extends Nimstead's Plain Sight identity, observed on nimstead.systems and in web/src/index.css. It is a Read surface: comprehension and wayfinding lead.

## Tokens

- Archivo for interface and prose; Geist Mono for code only. Self-hosted assets.
- Light: paper #ffffff, rail #f6f6f5, ink #111111, muted #5c5c5c, line #e4e4e2.
- Dark: paper #111111, rail #191919, ink #f2f2f0, muted #b1b1ae, line #333333.
- Brand seal #b0122c. Ink focus rings; red is not a generic action colour.
- Square controls, no decorative shadow, no gradients.
- Body 17px / 1.7, article measure 70ch. Headings 40/28/21px with -0.025em tracking.
- Spacing scale: 4, 8, 12, 16, 24, 32, 48, 64px.

## Structure

A compact masthead, persistent documentation rail, calm reading column, and on-page outline. The homepage is a directory with four clearly described reading modes. No marketing hero or invented proof metrics.

Desktop retains navigation and outline. Tablet hides the outline. Mobile places navigation in an explicit expandable section, preserving access without JavaScript. Search is a separate page with live results, a clear loading state, and recoverable errors. Theme follows the system unless selected explicitly.

## Interaction and access

44px controls, visible keyboard focus, skip link, semantic landmarks, current-page labels, native details and select controls, scrollable code and tables, reduced-motion support, print layout. Copy feedback is announced. Search terms remain local to the browser.
